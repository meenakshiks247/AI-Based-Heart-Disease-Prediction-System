# Frontend — Minimal Placeholder

## Quick Start

```bash
cd frontend
npm install
npm run dev
```

This is a minimal placeholder front-end scaffold.
It can be replaced with a full React app later.

## Notes

- Uses **Vite** as the dev server / bundler.
- Uses **React 18** for rendering.
- No backend API calls are made — this is only a placeholder.
- The `START_SYSTEM.ps1` orchestrator expects this directory to exist.
